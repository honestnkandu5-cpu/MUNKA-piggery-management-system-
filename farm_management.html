Farm Management

Select a registered farm to view, edit, or assign its Owner/Admin.
Enter a new name when registering a new farm.
Select the registered Owner/Admin who should have access to this farm. The system will connect this user to the farm using the user's farm ID.

Farm Access

Access relationship: Owner/Admin → Farm ID

The selected Owner/Admin will be assigned to this farm. When the user logs in, the system will identify their farm through farm_id.

Farm access will also depend on the farm being active and having a valid subscription.
